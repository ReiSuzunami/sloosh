# Code of Conduct

Sloosh welcomes respectful, constructive participation in issues, pull
requests, reviews, and other project spaces.

Expected behavior:

- discuss ideas and code, not personal traits;
- give actionable feedback and assume good faith;
- respect different experience levels and viewpoints;
- protect private and security-sensitive information.

Unacceptable behavior includes harassment, discrimination, threats, doxxing,
deliberate disruption, and publishing exploit details or another person's
private information without permission.

Project maintainers may edit or remove content and temporarily or permanently
limit participation when needed to keep project spaces safe and productive.
Enforcement decisions consider context, impact, and repeated behavior.

Report conduct concerns privately using contact information on the maintainer's
GitHub profile. Report product vulnerabilities through the private process in
[SECURITY.md](SECURITY.md), not through a public conduct report or issue.
